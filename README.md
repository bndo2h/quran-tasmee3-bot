# Quran Tasmee Bot

بوت Telegram خاص لتجربة تسميع القرآن.

## ماذا يفعل؟
- اختيار السورة والآية.
- استقبال Voice من Telegram.
- تحويل التسجيل إلى نص عربي.
- مقارنة النص بالآية.
- إظهار مواضع الاختلاف ونسبة مطابقة تقريبية.

## مهم
هذه النسخة التجريبية تحتوي على سورة الفاتحة فقط كمثال. قبل الاعتماد عليها لتسميع بقية القرآن، يجب إدخال نص القرآن كاملًا من مصدر موثوق/مرخص، وعدم اعتبار نسبة المطابقة حكمًا شرعيًا أو تقييمًا متخصصًا للتجويد.

## التشغيل محليًا

1. ثبتي Python 3.12 أو أحدث.
2. افتحي الطرفية داخل المجلد.
3. أنشئي بيئة:
   python -m venv .venv
4. فعّليها.
5. ثبتي المتطلبات:
   pip install -r requirements.txt
6. انسخي `.env.example` إلى `.env` وضعي القيم.
7. شغلي:
   python bot.py

يمكن أيضًا تشغيل Docker:
docker build -t quran-tasmee .
docker run --env-file .env quran-tasmee
